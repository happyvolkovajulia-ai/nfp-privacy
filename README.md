# Публикация страницы политики конфиденциальности

Эта папка — маленький отдельный сайт: **только страница политики
конфиденциальности** (`index.html`). Он нужен, чтобы дать RuStore публичную
ссылку на политику, не открывая всему интернету исходный код приложения.

## Порядок действий

### 1. Создайте пустой публичный репозиторий

1. Откройте https://github.com/new
2. Repository name: `nfp-privacy`
3. Visibility: **Public** (для GitHub Pages на бесплатном тарифе репозиторий
   должен быть публичным — но здесь лежит только страница политики, кода нет)
4. **Не** ставьте галочки «Add a README file», «Add .gitignore», «Choose a
   license» — репозиторий должен быть пустым.
5. Нажмите **Create repository**.

### 2. Отправьте страницу

Выполните в PowerShell (одна команда):

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\ivan\Desktop\nfp-privacy\push.ps1"
```

### 3. Включите GitHub Pages

1. В новом репозитории: **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, папка **/ (root)** → **Save**
4. Через 1–2 минуты страница будет доступна по адресу:

   **https://happyvolkovajulia-ai.github.io/nfp-privacy/**

   Эту ссылку указывайте в карточке RuStore (поле «Политика
   конфиденциальности») и в анкетах.

### 4. Закройте основной репозиторий с кодом

После того как ссылка на политику заработала:

1. Откройте https://github.com/happyvolkovajulia-ai/ru.nfp.calculator/settings
2. Прокрутите до раздела **Danger Zone** → **Change repository visibility** →
   **Make private** → подтвердите (нужно ввести имя репозитория).

Код перестанет быть виден кому-либо, кроме вас. Уже опубликованные страницы
GitHub Pages у приватного репозитория на бесплатном тарифе отключаются — поэтому
политику и держим в отдельном публичном репозитории.

## Если понадобится обновить политику

Отредактируйте `index.html` в этой папке и снова запустите `push.ps1` —
страница обновится через минуту.
